# Patcher (`patcher/`)

Interactive CLI (promptui). Reads plugin names from `plugins_patch.go.txt` (one per line) and adds game-specific Cheat Menu extensions found as `Cheat_Menu.<name>.js` in `www/js/plugins/` or `js/plugins/` (`extensions.go`, deduplicated, blank / CRLF-safe), prompts whether to back up `plugins.js`, then prompts for engine type. Engine detection is by `plugins.js` location: MV = `www/js/plugins.js`, MZ = `js/plugins.js`; **Auto** probes those paths and runs only the matching engine. `InjectPatchPlugin` parses `plugins.js` with the otto JS parser and splices a plugin entry into the `$plugins` array; an already-present plugin is a yellow "skipping" warning, not an error. `plugins.js.bak` is written at most once, before the first successful write, and never overwrites an existing one (it keeps the game's original `plugins.js` across re-runs). MZ additionally copies the plugin `.js` (and its `.css`, if present; for `Cheat_Menu` also `Cheat_Menu.dictionary.json`, if present) from `www/js/plugins/` to `js/plugins/` (`PostPatch`; a plugin that is only in `js/plugins/` is left as it is) — this also runs when the plugin entry already exists, so re-running the patcher refreshes an updated plugin file. Build with `go build` in `patcher/` (or via `pnpm build:release`); run tests with `go test ./...` in `patcher/` (`rpg_maker_type_test.go` covers engine resolution, injection, backup semantics, and MZ PostPatch; `extensions_test.go` covers extension discovery).
